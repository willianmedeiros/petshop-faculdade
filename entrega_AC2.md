# Sistema PetShop - Entrega AC2

Este projeto foi feito para a disciplina de **Software Program Specification** baseada no Manifesto Ágil.

O projeto consiste num sistema web para a gestão de um PetShop, estruturado com back-end em PHP (PDO), front-end clássico (HTML e CSS) e banco de dados relacional (MySQL). 

A entrega desta segunda fase (AC2) tem como foco a evolução da interface para um Dashboard com menu lateral, visualização e edição de registros via PopUP Modal, exclusão em efeito cascata (CASCADE) no banco de dados, além de melhorias no cadastro de pets com novos campos de idade, foto e observações/preferências.
